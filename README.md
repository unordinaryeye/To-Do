# Daily Routine

매일 반복하는 루틴과 하루짜리 할 일을 한 화면에서 관리하는 개인용 웹앱입니다. 아이폰 홈 화면에 추가하면 앱처럼 씁니다. 서버 없이 정적 파일로 동작하고, 기록은 기기(localStorage)에 저장되며 원하면 Firebase로 기기 간 동기화합니다.

- 주소: **https://myroutine.web.app** (예전 주소 https://unordinaryeye.github.io/To-Do/ 도 계속 동작)
- 빌드 없음. `index.html` + `src/` ES module + `styles/` 그대로 배포.

---

## 1. 설치 (아이폰)

1. **Safari**로 위 주소 접속 (Chrome은 홈 화면 추가가 안 됩니다)
2. 하단 **공유 버튼(↑)** → **홈 화면에 추가** → 추가
3. 홈 화면의 초록 체크 아이콘으로 실행

처음 한 번 온라인에서 열어 두면 이후엔 오프라인에서도 열립니다. 새 버전은 앱을 껐다가 두 번 켜면 적용됩니다.

---

## 2. 화면 구성

하단 탭 4개와 가운데 **+** 버튼.

| 탭 | 하는 일 |
|---|---|
| 🏠 홈 | 오늘의 루틴 체크, 투두 관리 |
| 📊 통계 | 월간 / 주간 / 초록불 |
| 🎯 목표 | 만다라트, 목표 태그 |
| 👤 내정보 | 동기화, 백업, 설정 |

**+ 버튼**을 누르면 "루틴 추가 / 투두 추가" 메뉴가 뜹니다.

---

## 3. 홈

### 주간 행
- 월~일 7일. 날짜 원 안의 **도넛**이 그날 달성률, 전부 달성하면 **초록불**(초록 원).
- 좌우 ‹ › 또는 스와이프로 주 이동, 위쪽 월 이름을 탭하면 오늘로.
- 🔥 숫자는 **연속 달성 일수**(예정된 루틴을 모두 끝낸 날의 연속). 예정이 없는 날은 끊기지 않습니다.
- ↕ 버튼: 루틴 순서변경 페이지.

### 루틴 탭
표 한 줄이 루틴 하나. **[시간·반복 요일] [이름] [체크]** 순서.

- **체크 셀**(맨 오른쪽) 탭 → 달성. 한 번 더 탭하면 취소. 하루 달성 수가 2회 이상인 루틴은 탭할 때마다 1/3 → 2/3 → 달성 → 해제로 돕니다.
- **시간·요일 셀** 탭 → 빠른 설정 시트. 시작/종료 날짜, 반복 요일(매일·평일·주말 프리셋 + 요일 칩), 시간 또는 상황("출근길") 트리거를 바로 고칩니다. 바뀐 설정은 오늘부터 적용되고 지난 기록은 그대로 남습니다.
- **이름 셀** 탭 → 액션 시트: 수정하기 / 시간·반복 바꾸기 / 위·아래 이동 / 월간 기록 / 복사하기 / 쉬어가기 / 끝내기 / 삭제하기
  - **쉬어가기**: 오늘만 · 내일까지 · 이번 주 · 일주일 · 기한 없이. 쉬는 동안 예정에서 빠지고 스트릭도 끊기지 않으며, 기간이 끝나면 자동으로 다시 예정됩니다.
  - **끝내기**: 오늘부터 예정에서 빠집니다. 기록은 남고 내정보 → 끝낸·쉬는 루틴에서 다시 시작할 수 있습니다.
- 시간이 있는 루틴은 **시간순으로 자동 정렬**됩니다(내정보에서 끌 수 있음).
- **"하루 ▾"** 칩을 탭하면 **주 보기**: 루틴 × 7일 격자에서 그날 칸을 탭해 바로 체크합니다(미래는 잠금).
- 그 옆 **목표 태그 칩**으로 필터, 끝의 ⚙로 태그 관리.

### 루틴 추가 / 수정 폼
- 이름 + 이모지, 추천 루틴 칩(이름·이모지·시간이 한 번에 채워짐)
- 시작 날짜 / 종료 날짜(선택)
- 반복: 매일 · 평일 · 주말 · 요일 직접 선택
- 시간: 지정 안 함 · 시간(아침/점심/저녁/밤 프리셋) · 상황(일어나자마자, 출근길 …)
- 하루 달성 수(1~10회), 알림(앱이 열려 있을 때 그 시간에 토스트)
- 목표 태그(여러 개 가능, "+ 새 목표"로 바로 만들기)
- 수정 모드 하단에 삭제

### 투두 탭
- **빠른 추가** 입력창: `14:00 병원`, `오후 3시 치과`, `2pm 택배`, `9시 반 커피`처럼 적으면 시간이 자동으로 붙습니다.
- 시간이 있는 항목은 시간순으로 먼저, 오늘 목록엔 **"지금"** 구분선이 표시되고 지난 시간에 미완료면 빨간 `!`.
- **☰ / ⊞**로 리스트 ⇄ **4분면 매트릭스** 전환. 매트릭스는 🔥⭐ 지금 하기 / ⭐ 계획하기 / 🔥 빨리 끝내기 / 나중에 4칸과 아래 미분류 보관함. 각 칸의 "+ 추가"는 우선순위가 미리 채워집니다.
- 이름 탭 → 액션 시트: 수정 / 사분면 이동 / 습관으로 만들기 / 위·아래 이동 / 삭제
- 📅 버튼으로 날짜 이동. 지난 미완료가 있으면 위에 **"오늘로 옮기기"** 배너.
- 투두 폼: 제목 / 🕒 시간 / 📅 날짜 / 🎯 우선순위(긴급·중요 칩)

---

## 4. 통계

- **월간**: 목표 달성률, 초록불 일수, 최장 연속, 투두 완료율, 루틴별 월 그리드(색칠=달성, 노랑=일부, 회색=미달성, 점선=예정 없음)
- **주간**: 루틴 × 요일 표(■ 완료 ◪ 일부 □ 미완료 – 예정 없음), 요일별 달성률
- **초록불**: 월 캘린더(● 초록불 ◑ 일부 ○ 0% ─ 예정 없음), 현재/최장 연속. 날짜를 탭하면 홈의 그날로 이동

---

## 5. 목표와 만다라트

목표 탭은 **만다라트 → 목표 → 루틴** 3단으로 들어갑니다.

1. **만다라트**: "+ 만다라트"로 핵심 목표(예: 건강한 한 해)를 만듭니다. 3×3 가운데가 핵심 목표.
2. **목표**: 주변 8칸의 빈 칸을 탭해 **목표 태그**(모닝 루틴, 건강 …)를 놓습니다. 시트에서 "새 목표 만들기"를 하면 그 칸에 바로 들어갑니다. 같은 목표는 한 칸에만 놓입니다.
3. **루틴**: 목표 칸을 탭하면 가운데가 그 목표, 주변 8칸에 **그 목표 태그가 붙은 루틴**이 자동으로 들어옵니다. 빈 칸을 탭하면 태그가 미리 붙은 루틴 추가 폼, 루틴 칸을 탭하면 액션 시트. 오늘 달성한 루틴엔 ✓, 이번 달 달성률이 배경으로 차오릅니다.

오른쪽 위 **표** 버튼으로 9×9 전체를 봅니다. 기존 루틴을 만다라트에 넣으려면 루틴 수정 → 목표 태그를 붙이면 됩니다.

목표 태그 목록에서 태그를 탭하면 수정·삭제. 삭제해도 루틴은 남고 태그만 빠집니다.

## 7. 자주 묻는 것

- **연속 일수가 안 오르는데요?** 그날 예정된 루틴을 **전부** 달성해야 초록불이 켜지고 하루가 더해집니다. 오늘 아직 다 못 했으면 어제까지의 값을 보여줍니다.
- **요일을 바꿨는데 지난 기록이 바뀌나요?** 아니요. 설정은 오늘부터 적용되고 과거 달성률은 그때 설정으로 계산됩니다.
- **알림이 안 와요.** 앱이 열려 있을 때만 동작합니다. 앱이 닫힌 상태의 푸시는 서버가 필요해 지원하지 않습니다.
- **새 버전이 안 보여요.** 앱을 완전히 종료했다가 두 번 켜 주세요. 첫 실행에서 새 파일을 받고 두 번째부터 적용됩니다.

## 8. 개발

```
python -m http.server 8765      # 로컬 미리보기 → http://localhost:8765/
node tests/run.mjs              # 도메인 테스트 (브라우저: /tests/index.html)
```

- 구조: `src/domain`(순수 계산) → `src/state`(store/reducer/selector) → `src/ui`(화면). `src/sync`는 Firestore, `src/storage`는 localStorage·백업.
- 데이터: 스키마 v3. 루틴은 `policies`(적용일 이력)로 반복·시간·상태를 저장하고, 설정 변경은 그날부터 적용됩니다. 예전 v2 데이터는 첫 실행 때 자동 변환됩니다.
- 계획과 결정 기록: `docs/plan/00-PLAN.md`
- Firestore 규칙: `firestore.rules` (콘솔에 게시해야 적용)
